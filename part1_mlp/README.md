# Часть 1

Из корня проекта: `python -m part1_mlp.app.main`.
Меню позволяет создать сеть, загрузить CSV, обучить, сделать предсказания,
сохранить/загрузить модель и график ошибки, сменить скрытую активацию.
Последняя колонка обучающего CSV содержит бинарную цель 0 или 1.
Для предсказания из CSV передаются только признаки с заголовками.

`DatasetManager` сначала разделяет строки на train/test и только затем
рассчитывает среднее и стандартное отклонение по train. Параметры
нормализации сохраняются в JSON вместе с весами. Нулевой разброс признака
заменяется единичным масштабом. Размеры и конечность чисел проверяются.

Модель использует MSE, мини-батчи и градиентный спуск. На выходе сигмоида,
в скрытых слоях можно выбрать sigmoid или ReLU. Активации наследуют общий
интерфейс, сеть состоит из объектов DenseLayer. Свои исключения
перехватываются на уровне консольного приложения.

Демонстрация: `python -m scripts.demo_mlp`.
Учебные данные создаются `python -m scripts.generate_samples`:
240 независимых зашумленных примеров XOR, seed=42. Это синтетический
пример, его результаты не оценивают качество на реальных задачах.
